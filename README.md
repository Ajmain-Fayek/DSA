## Problems

### <p color:"blue"> Problem set - 1: String Compression</p>

Write a function that takes a string and returns a **_compressed_** version. If a character repeats, replace the repetition with the count of characters.

**Input:** `"aaabbcbba"` </br>
**Output:** `"a3b2c1b2a1"`</br>
**Goal:** This tests your ability to handle loops and conditional logic within a single string traversal.

---

### Problem set - 2: Two Sum Logic

Given an array of integers and a target number, return the indices of the two numbers that add up to that target.

**Input:** `[2, 7, 11, 18]` </br>
**Target:** `9` </br>
**Output:** `[0, 1]` </br>
**Goal:** This is a classic "Big O" complexity test. A junior might use a nested loop (O(n²)), but a high-performing intern might mention using a Hash Map/Dictionary for a faster solution.

---

### Problem set - 3: Palindrome & Cleanliness

Check if a string is a palindrome (reads the same backward as forward), but you must ignore spaces, punctuation, and capitalization.

**Input:** `"Race Car"` </br>
**Output:** `True` </br>
**Goal:** This tests your knowledge of built-in methods (like `.toLowerCase()` or `Regex`) and how you clean data before processing it—a vital skill for web development.
